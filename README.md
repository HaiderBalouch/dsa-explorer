# dsa-explorer
Interactive PyGame visualiser for core data structures and algorithms - stacks, queues, linked lists, BSTs, sorting, graphs, and heaps.

DSA Explorer

An interactive visualisation tool for learning and exploring data structures and algorithms.

DSA Explorer uses Python and Pygame to provide visual representations of common data structures and algorithms, allowing you to see how they behave as operations are performed.

Overview

Understanding data structures and algorithms can be difficult when they're presented only through code. DSA Explorer aims to make these concepts easier to understand by showing their behaviour visually.

The project currently includes visualisations for:

Stacks
Queues
Linked Lists
Binary Search Trees
Sorting Algorithms
Graphs
Heaps

Each visualisation is designed to show how data changes as different operations are performed.

Features
Data Structures

Stack

Visualise the Last In, First Out (LIFO) structure and its fundamental operations.

Queue

Explore the First In, First Out (FIFO) structure and how elements are added and removed.

Linked List

See how nodes are connected and how insertion, deletion, and traversal affect the structure.

Binary Search Tree

Visualise how values are organised within a binary search tree and how operations such as insertion and searching work.

Graph

Explore relationships between nodes and edges through an interactive graph representation.

Heap

Visualise how elements are organised within a heap and how the heap property is maintained.

Algorithms

Sorting

Watch sorting algorithms operate on a collection of elements and see comparisons and rearrangements happen visually.

Getting Started
Requirements
Python 3
Pygame
Installation

Clone the repository:

git clone https://github.com/HaiderBalouch/dsa-explorer.git
cd dsa-explorer

Install the required dependency:

pip install pygame
Running the Application

Run the project using:

python -m dsa_explorer

Why This Project?

DSA Explorer was built as a way to combine programming with visual learning.

Rather than treating a data structure as an abstract collection of operations, the application provides a visual representation of what is happening internally.

This makes it useful for:

Learning fundamental DSA concepts
Reviewing concepts while studying
Understanding algorithm behaviour
Experimenting with different structures
Developing a stronger intuition for how algorithms work
